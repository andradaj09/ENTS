1. Criterios de construcción

  • Orientada a entregables: cada elemento representa un resultado verificable, no una tarea suelta.
  • Regla del 100%: la EDT incluye todo el trabajo del proyecto y nada que esté fuera del alcance aprobado.
  • Tres niveles: proyecto (nivel 1), componentes (nivel 2) y paquetes de trabajo (nivel 3).
  • Codificación jerárquica: cada paquete se identifica con un código (por ejemplo, 1.4.3) que se usa en la lista y el diccionario de actividades.
